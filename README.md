# Kirima Rise

> **Kirima Rise** is an entity of the Estate of G.K. Kirima, representing heritage, trust, generational stability, and premier property regularisation and development.

---

## 🏛️ Project Overview

This repository hosts the official website, design assets, and brand implementation for **Kirima Rise**.

- **Official Brand Design Guidelines**: Documented in [`design.md`](./design.md) and [`KIRIMA Rise Brand Guidelines 2.09.26.pdf`](./KIRIMA%20Rise%20Brand%20Guidelines%202.09.26.pdf).
- **Core Visual Identity**:
  - **Kirima Red** (`#bo1f24` / Pantone 2357 C)
  - **Heritage Forest Green** (`#00491E` / Pantone 3537 C)
  - **Warm Sand / Cream** (`#FAF7F2`) & Pure White (`#FFFFFF`)

---

## 📁 Repository Structure

- `index.html` — Main website homepage
- `brand-design.css` — Core brand design system styles & typography tokens
- `brand-header.js` — Navigation header component logic
- `send-enquiry.php` — Enquiry & contact handling endpoint
- `about/` — About page resources
- `our-heritage/` — Heritage and history section
- `sample-page/` — Sample layouts and page templates
- `wp-content/`, `wp-includes/`, `wp-json/` — Static assets and content
- `design.md` — Detailed brand and UI specification guidelines

---

## 🚀 Getting Started

To view the website locally, serve the project root using any local static or PHP web server, for example:

```bash
# Using PHP built-in server (recommended for enquiry form handling)
php -S localhost:8000

# Or using Python for static preview
python -m http.server 8000
```

Then visit `http://localhost:8000` in your web browser.
